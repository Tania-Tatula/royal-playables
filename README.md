# Royal Playables

Two mobile-friendly, English-language browser games with original AI-generated illustrations.

- **Restore the Royal Portrait** — Slide tiles into the gap to restore the king’s portrait. Two guided moves lead into the free-play portion of a ten-move solution with all eight tiles out of place.
- **Find the Royal Things** — Find four items in the royal dressing room. The crown and checklist glow at the start. Find the rest in any order.

## Play locally

Open `docs/portrait/index.html` or `docs/search/index.html` directly in a browser.

## GitHub Pages

Upload the repository contents, then set **Settings → Pages → Deploy from a branch → main → /docs**. Once the deployment finishes, append `portrait/` or `search/` to the GitHub Pages URL for direct links.
